# mavericklabsresearch.github.io

Website for Maverick Labs AI and Robotics — mavericklabsresearch.org.
Plain static HTML on GitHub Pages — the publishing pattern follows
substrateresearch.org (edit the HTML, push to main, Pages serves it at the
custom domain in CNAME), but with its own "Digital Wonder" theme in
assets/site.css, deliberately unlike Substrate's newspaper style.
